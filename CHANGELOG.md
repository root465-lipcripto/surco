# Changelog

## 0.1.0

- Native C17 library and CLI with bounded-block storage, temporal lookup,
  integrity checks, conservative recovery and replay.
- Format v1 with explicit little-endian framing, delta and delta-of-delta,
  integer bit packing, run lengths and raw fallback.
- Portable C and AMD64 NASM SSE2 transforms with optional SSE4.2 CRC32C.
- CSV and USB serial input, Python verification and offline visualization,
  and Linux x86-64 packaging.
